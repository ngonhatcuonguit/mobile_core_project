# Vietnam administrative address data

`vietnam_legacy_districts.json` is an offline snapshot of the Province Open
API v1 district catalog: https://provinces.open-api.vn/api/v1/?depth=2

The app maps these legacy district-level address areas to Vietnam's 34
provincial-level units effective from July 1, 2025. Districts are retained for
address compatibility; they are no longer a current administrative tier.
