# Work Schedule Notification Sounds

## Android
Place `alert_sound.mp3` in this directory.

The file should be:
- Format: MP3 or OGG
- Duration: 2-3 seconds
- Sample: Alert/Warning sound (e.g. beep-beep-beep)

## iOS
Place `alert_sound.aiff` in `ios/Runner/Resources/`

## Suggested Sources
- https://mixkit.co/free-sound-effects/alarm/
- https://freesound.org/search/?q=alert
- https://notificationsounds.com/

## Default Behavior
If custom sounds are not provided, system default notification sound will be used.
